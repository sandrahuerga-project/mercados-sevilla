Cómo implementar la comprobación de mercado_fav en Landbot
(no necesitas otro “Start”; solo añadiremos un bloque condicional justo después del inicio).

1. Estructura que vas a montar
Start
  ↓
Check Mercado (Conditional)   ← aquí se evalúa si existe mercado_fav
   ├─ 1) mercado_fav NO vacío → Bloque “Confirmar mercado” (Message + Buttons)
   │         • Botón “Usar @mercado_fav”   → salta al sub-flujo Pedido
   │         • Botón “Cambiar mercado”     → bloque Elegir Mercado
   └─ 2) mercado_fav vacío   → bloque Elegir Mercado (lista de mercados)
2. Paso a paso en el builder de Landbot
2.1 Coloca el bloque condicional justo tras el Start
Haz clic en el círculo gris del Start y arrastra hasta Logic → Conditional logic.

Renombra el bloque a “Check mercado_fav” (doble clic en el título).

2.2 Configura la condición
En el panel derecho selecciona:

IF: elige la variable mercado_fav

Operator: is NOT

Value type: empty
(Landbot mostrará algo como “is not empty”)

Con esto estás diciendo: “Si mercado_fav existe y no está vacío…”.

Pulsa Save.

2.3 Crea los dos caminos
Conector verde (la condición que acabas de crear) → arrástralo a un nuevo bloque Message, llámalo “Confirmar mercado”.

Conector gris “Else” (no-condition) → arrástralo al bloque Elegir Mercado donde el usuario selecciona por primera vez.

2.4 Bloque Confirmar mercado
Tipo: Message con botones.

Texto:

Tu mercado favorito es **@mercado_fav**.
¿Quieres comprar allí hoy?
Añade dos botones:

Usar este mercado

Conecta a Sub-flujo Pedido (o directamente al bloque Categoría).

Cambiar mercado

Conecta de nuevo al bloque Elegir Mercado.

Nota: en el texto puedes mostrar la variable usando @mercado_fav.

2.5 Bloque Elegir Mercado
Ya lo tienes de antes (botones Triana, Cerro, etc.). Al final de ese bloque continúas al sub-flujo de pedido.

3. ¿De dónde sale mercado_fav la primera vez?
En tu bloque Elegir Mercado (cuando el usuario selecciona por primera vez), asegúrate de Guardar la respuesta en:

mercado_fav
Landbot guarda esa variable en la conversación; en sesiones siguientes la recordará, por eso “Check mercado_fav” podrá detectarla.

4. Comprobación rápida
Primer test: nuevo chat (sin variable):

Bot debería llevarte al bloque Elegir Mercado.

Segundo test: mismo chat, segunda vuelta:

Bot debe saltar al mensaje “Tu mercado favorito es…” y ofrecer los dos botones.

Resumen de bloques (nombres sugeridos)
Orden	Bloque	Tipo	Variable / Acción
1	Start	—	—
2	Check mercado_fav	Conditional	mercado_fav is not empty
3a	Confirmar mercado	Message + Buttons	muestra @mercado_fav
3b	Elegir Mercado	Question → Buttons	guarda en mercado_fav
4	(Sub-flujo Pedido)	—	categorías, productos, etc.
Con esto tu “else” está implementado: el conector gris del bloque condicional. Solo asegúrate de conectar cada rama al bloque correcto y de guardar la variable mercado_fav la primera vez.

¡Buena pregunta! En Landbot, el camino “Else” (o "si no se cumple la condición") se configura automáticamente como una de las ramas de tu bloque Conditional. Aquí te explico paso a paso cómo hacerlo:

✅ CÓMO CONFIGURAR EL ELSE (cuando la condición no se cumple):
Añade el bloque “Conditional” si no lo has hecho ya.

En el bloque Conditional:

Variable: @mercado_fav

Condición: IS SET
(esto cubre el caso de que ya haya elegido mercado antes)

Ahora verás dos caminos:

Uno que dice YES (cuando la condición sí se cumple → el mercado ya está guardado)

Otro que dice NO (cuando no está guardado aún)

Conecta el bloque del camino NO (Else) a tu bloque Elegir Mercado.

🎯 Ejemplo visual de lógica
Start
 ↓
[Conditional: @mercado_fav IS SET]
   ├── YES → [Mensaje: "Compras en @mercado_fav?"]
   │           ├── Botón "Sí" → subflujo Pedido
   │           └── Botón "Cambiar mercado" → Elegir Mercado
   └── NO → [Elegir Mercado]
Con eso ya tienes el flujo que diferencia entre usuario nuevo y repetidor.
